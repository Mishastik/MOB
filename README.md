# Expense Tracker - Трекер личных расходов

## Автор
Щепетков Михаил Алексеевич

## Описание программы
Expense Tracker - это десктопное приложение для отслеживания личных расходов, разработанное на Python с использованием библиотеки Tkinter. Приложение позволяет вести учёт расходов, фильтровать записи по категориям и датам, а также подсчитывать сумму расходов за выбранный период.

## Возможности
- Добавление расходов с указанием суммы, категории и даты
- Валидация вводимых данных (положительная сумма, корректный формат даты ГГГГ-ММ-ДД)
- Фильтрация расходов по категории и временным периодам (сегодня, неделя, месяц, год)
- Подсчёт суммы расходов за произвольный период
- Сохранение и загрузка данных в формате JSON
- Удаление записей
- Интуитивно понятный графический интерфейс
